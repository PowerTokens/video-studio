PowerTokens Video Studio v1.10 - Windows desktop tool for Wan 3.0 video generation

Easiest: download PowerTokensVideoStudio.exe from the GitHub Releases page.

Run from source:
1. Extract the whole ZIP.
2. Install Python 3.11+ for Windows (include Tcl/Tk and "Add python.exe to PATH").
3. Double-click Start.bat.
4. Add your PowerTokens API Key in the API Key tab, then generate a video.

Build a standalone EXE: run Build-EXE.bat on Windows.
Output: dist\PowerTokensVideoStudio.exe
